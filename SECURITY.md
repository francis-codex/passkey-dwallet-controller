# Security policy

## Supported versions

This program is pre-mainnet and deployed to devnet only. Only the latest commit on `main` is supported.

## Reporting a vulnerability

Please do not open a public issue. Report privately through either:

- GitHub's [private vulnerability reporting](https://github.com/seedless-labs/passkey-dwallet-controller/security/advisories/new), or
- email to francis@seedlesslabs.xyz

Include the affected instruction or file, steps to reproduce, and the impact you expect. You will get a reply within 3 business days, and a fix or plan within 14 days for confirmed issues. We credit reporters in the release notes unless you ask us not to.
